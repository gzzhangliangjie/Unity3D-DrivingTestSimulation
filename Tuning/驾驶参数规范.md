# 科目二演示·速度与路线规范（定版）

> 2026-11-04 固化。改驾驶参数前先读这份文档。

## 一、速度规范：全程恒速 6.5 km/h

- **直角转弯（Zjzw）**：vApproach = vCorner = vExit = **6.5**，全程一个速度，无加减速循环
- **曲线行驶（Qxxs）**：vApproach = vCurve = vExit = **6.5**，同上
- **侧方停车（Cftc）**：前进 / 倒车 / 出库全程 = **6.5**（含倒车入库段）——倒车段不降速，靠精准停点（`_preciseStop` + `_stopReach=0.25`）在库位前硬刹停；无对应 `cftc_tuning.json`，代码默认值即唯一真值
- 考试原则：不主动加速、不画蛇——只有"起步到巡航"和"保持"
- 代码默认值（DemoDriver.cs）与 `Tuning/zjzw_tuning.json` / `qxxs_tuning.json` 必须一致，改一处要同步另一处

## 二、直角转弯·靠右预留（关键几何参数）

- `routeEntryOffset = 0.35`（米）：入弯前车道中心线**向南侧/外侧偏 0.35m**，即"靠右行驶"
- 原理：满舵最小半径 3.33m vs 需要的 3.2m，**半径零余量**——弧线任何向内的偏差都会扫到内角墙 (34.4,-31.6) 附近。靠右预留 ~0.35m 是唯一稳健的余量来源（科目二教学动作：入弯前靠右）
- 其余几何参数（radiusMax=3.2、exitX=36.42、entryZ=-33.5）沿用实车标定值，**不要动**

## 三、油门/限速层的配套约束（防回归）

这些下限的语义是"兜底"，**必须高于恒速目标 6.5**，否则会把弯中速度悄悄钳回去：

| 参数 | 值 | 位置 |
|---|---|---|
| 转角限速下限 `_capSpeedLow` | **7** | DemoDriver.cs |
| 打舵限速（`|steer|>0.5` 时） | **7** | DemoDriver.cs UpdateRun |
| 路线模式油门死区 | **0.2** | 同上 |
| 路线模式油门增益 / 下限 | **0.6 / 0.35** | 同上（满舵死弯阻力大，弱油门顶不住目标速度） |

### 控制参数（BuildDcrkWps 末尾，勿随手改）

```csharp
_speeds 全 46 点 = 6.5f;      // 全程恒速，倒库段不降速（低速会让满舵爬升吃掉 0.9m 点位余量）
_preciseStop = true;  _stopReach = 0.7f;   // 四个停点必须进 2m 窗 / Ab 窗
_lookReverseOverride = 3.5f;              // 倒车前瞻；改大就切内弯扫库口
_ffSpanFix = false;                       // 位姿满舵下关掉曲率前馈跨度修正
_revSteerCap = 1.0f;                      // 打满，不钳 0.88
_dcrkLockX = -67.4f;  _dcrkLockX2 = -76.3f;
出库直出保护阈值：第一次 pos.z < -38.38f，第二次 pos.z < -37.90f
```

### 三条硬教训

1. **出库打舵点 = 驾驶座过库口线**，不是"车尾完全出库口"。等车尾出完（车心 -35.83，再留余量 -35.2）时车已直冲出 3m，满舵后弧顶直接怼北墙 `contact(-72.42,-31.06)`，扣 100 分。几何上：弧顶 z = 打舵点 z + 4.1（半径），要落在行驶线 -33.55 上，打舵点必须是 **-37.5 附近**，与实测定版 -38.0 吻合。
2. **两段出库不对称**：往东转（第二次）车尾甩向东翼，实测尾角余量只剩 0.34m（往西有 0.71m），故第二次阈值单独推后 0.5m 到 -37.90。
3. **打满靠位姿条件，不靠追点**：`x ≤ _dcrkLockX` 且 yaw 已起转即刻满舵，yaw 回正即回正 —— 与前瞻距离/路点疏密解耦，确定性远高于纯跟踪。

## 三·六、侧方停车（Cftc）位姿收车（2026-11-05 定版）

### 几何与判定窗（field_data）
- 车道 Z[-30.25,-26.62]；库位 X[-17.75,-9.74] Z[-32.87,-30.25]（深 2.62m）
- Det_CFTC 入库判据 `Ab = 车心z + 32.806 ≤ 1.65` → **车心 z ≤ -31.156**；库底约 -31.7
- 可用带宽只有约 0.5m，靠"距路点多远"收车必然漂

### 控制参数（BuildCftcPath / SyncSegParams 的 Cftc 分支）
```csharp
_preciseStop = true;  _stopReach = 1.05f;   // 距离触发仅作兜底
_lookReverseOverride = -1f;                 // = 用 _lookReverse 2.6m（写 3.5 会让弧提前起弯、停不到位）
_revSteerCap = 1.0f;
_cftcStopByPose = true;                     // 侧方入库按位姿收车
_cftcStopZ = -31.15f;                       // 车心 z ≤ 此值即刹停；刹停滑行 ~0.1m，实测停稳 -31.3~-31.35
```

### 实测关键帧（v1116-0135 单科一轮，0 扣分 = 100）
```
(-12.9,-30.6) yaw70  steer -1.00     摆正段
(-13.6,-31.1) yaw81  steer -1.00
[位姿收车] (-13.89,-31.23) yaw87 Ab=1.58 (窗线 1.65) distWp=1.25
停稳后倒车帧 (-14.3,-31.3) yaw92 → 挂 D 出库
```
停点余量：窗线 0.07m、库底约 0.4m（Ab 越小越靠里，确认没有压库底）。

### 两条硬教训
1. **"参数写了"不等于"生效"**：5025eb2 里 BuildCftcPath 写 `_lookReverseOverride = 3.5f`，但 StartDemo 尾部（BuildPath 之后）有一行 `= -1f` 把它覆盖 —— 那次 100 分实际跑的是 2.6m。v27 为修倒库把清理移到 BuildPath 之前，3.5 突然复活 → 停点从 (-14.3,-31.4) 漂到 (-13.9,-30.9)、Ab=1.90>1.65，判两次中途停车（90 分），视觉就是"后轮没入库就打方向"。以后新增可覆盖参数必须打进 [DEMO] 遥测。
2. **停车用位姿，不用距离**：距离量随前瞻/路点疏密漂 ±0.3m，位姿阈值确定性收车，改前瞻不再影响停点。

## 四、已知教训（不要重蹈）

1. **任何把弯中实际速度压到 6.0 以下的改动都会内切撞墙**：速度低 → 轮胎侧偏小 → 实际弧线比标定模型紧 → 吃掉内角余量。历史上限速 4.5、油门大死区、钳制下限 6 都栽在这里。
2. **JSON 会覆盖代码默认值**：ZjzwTuner/QxxsTuner 跑批时以 Tuning/*.json 为准；单跑（ExamSimRunner）用代码默认值。两处不一致 = 两种行为。
3. **Play 中触发编译/域重载会杀批次并卡死在结算界面**：改代码后先编译、确认 `check_compile.py` 通过，再布防跑批。
4. **编辑器失焦时 Update 不 tick**：flag 无人消费时先 `python Tuning/focus_unity.py` 唤醒。
